# Code of Conduct

RamPilot adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. The full text is incorporated here by reference.

## In short

We want participation in this project to be a harassment-free experience for everyone. Be respectful,
assume good faith, accept constructive criticism, and focus on what is best for the project and its users.
Harassment, insults, personal or political attacks, publishing others' private information, and other
conduct that would be inappropriate in a professional setting are not acceptable.

## Scope

This code applies in all project spaces (issues, pull requests, discussions, reviews) and when someone
represents the project in public.

## Reporting

Report unacceptable behaviour privately. Do not use public issues for this. There are two channels:

- **To the maintainers:** open the repository's
  [Security tab](https://github.com/ilkerprdal/RamPilot/security) and choose **Report a vulnerability**
  (a private advisory, visible only to the maintainers). Start the title with "Conduct:". It is not a
  vulnerability, but it is the channel GitHub keeps private.
- **To GitHub:** use GitHub's [content reporting](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
  ("Report content" on a comment, or "Block or report" on a user profile). Use this channel if the behaviour
  involves a maintainer.

All reports are reviewed promptly and handled confidentially.

## Enforcement

Maintainers apply the
[enforcement guidelines of the Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban and permanent ban, depending on the severity and pattern of the behaviour.
